---

## About

**Spider Web — Part 2** is an interactive portfolio created to represent my developer journey as a connected web rather than a traditional portfolio.

Instead of separating everything into normal sections such as About, Skills, and Projects, I placed **Parthu at the center of the web** and connected the different areas of my work around it.

The web represents the relationship between my:

- Projects
- Skills
- Technologies
- Interests
- Experiences
- Achievements

The idea is simple:

> **Every project is a strand. Every skill is a connection. Together, they form my web.**

---

## Why I Created It

I wanted to create a portfolio that was different from the usual developer portfolio.

Most portfolios are designed to be scrolled through. I wanted mine to be **explored**.

Because my interests span different areas such as **AI/ML, cybersecurity, web development, IoT, game development, and startup/product building**, I wanted a design that could show how these areas are connected instead of presenting them as completely separate sections.

That led to the idea of building my portfolio as an **interactive spider web**.

---

## Inspiration

The main inspiration came from the concept of a **spider web**.

A web is made from many individual strands, but what makes it meaningful is how those strands connect with each other.

I used the same idea for my portfolio.

A skill can connect to multiple projects.

A project can use multiple technologies.

A technology can belong to multiple domains.

Those relationships create the complete web.

The visual concept was also inspired by the futuristic feeling of **Spider-Verse, Spider-Sense, web-slinging, digital HUD interfaces, and interactive technology**.

The implementation is designed as an original developer experience rather than a direct recreation of Spider-Man or Marvel assets.

---

## How I Created It

I created the website as an interactive network where the central node represents **PARTHU**.

The surrounding nodes represent different areas of my development journey.

```text
                         AI / ML
                            |
                            |
              CYBER ──── PARTHU ──── WEB
                            |
                            |
                           IoT
                            |
                       HACKATHONS
                            |
                         PROJECTS
```

The network is interactive instead of being a static illustration.

Users can explore the nodes, interact with the connections, and discover different parts of the portfolio.

Selecting a project or skill reveals its related information and connections.

---

## The Idea Behind Part 2

**Spider Web — Part 2** takes the original portfolio concept further by making the relationships between my work the main part of the experience.

Instead of simply asking:

> What projects has Parthu built?

the website asks:

> **How are Parthu's projects, skills, technologies, and interests connected?**

That is the core idea behind this version.
